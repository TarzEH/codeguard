# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |

Only the latest minor release receives security patches.

## Reporting a vulnerability

**Do not open a public issue.** Instead, email **oriash94@gmail.com** with:

1. A description of the vulnerability.
2. Steps to reproduce or a proof of concept.
3. The impact you believe it has.

You will receive an acknowledgement within **48 hours** and a detailed response within **7 days**.

## Responsible disclosure

We follow a **90-day disclosure timeline**:

- Once a report is confirmed, we will work on a fix and coordinate a release.
- We aim to publish a patched version within **90 days** of the initial report.
- We will credit reporters in the release notes (unless you prefer anonymity).

We appreciate your help in keeping CodeGuard and its users safe.
